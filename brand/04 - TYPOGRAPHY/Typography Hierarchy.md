# Typography Hierarchy

| Level | Face | Screen | Print | Tracking | Use |
| --- | --- | --- | --- | --- | --- |
| **Display** | Fraunces | 68px / 1.08 | 34pt / 36pt | -0.02em | Homepage hero only |
| **H1** | Fraunces | 44px / 1.15 | 24pt / 28pt | -0.02em | Page titles |
| **H2** | Fraunces | 32px / 1.2 | 18pt / 22pt | -0.02em | Section headings |
| **H3** | Fraunces | 22px / 1.3 | 14pt / 18pt | -0.01em | Sub-headings, card titles |
| **Body Large** | Inter | 18px / 1.7 | 11pt / 16pt | 0 | Intros, standfirsts |
| **Body** | Inter | 16px / 1.7 | 10pt / 15pt | 0 | Default reading size |
| **Small** | Inter | 14px / 1.6 | 9pt / 13pt | 0 | Captions, table cells, footnotes |
| **Eyebrow** | Inter | 12px / 1.4 | 7.5pt / 11pt | 0.2em | Uppercase section labels above headings |

## Rules

- One Display or H1 per page. Never two.
- Heading levels are never skipped — an H3 always sits under an H2.
- The eyebrow label is not a heading. It labels the section that follows and carries no
  heading semantics in markup.
- Body copy is never centred over more than two lines.
