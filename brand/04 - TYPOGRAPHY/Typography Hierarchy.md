# Typography Hierarchy

All Montserrat. The levels differ by weight, size and tracking.

| Level | Weight | Screen | Print | Tracking | Use |
| --- | --- | --- | --- | --- | --- |
| **Display** | 600 | 64px / 1.12 | 32pt / 36pt | -0.025em | Homepage hero only |
| **H1** | 600 | 52px / 1.18 | 26pt / 31pt | -0.025em | Page titles |
| **H2** | 600 | 44px / 1.15 | 22pt / 26pt | -0.02em | Section headings |
| **H3** | 600 | 28px / 1.3 | 14pt / 18pt | -0.02em | Service and article titles |
| **H4** | 600 | 18px / 1.45 | 11pt / 16pt | -0.01em | Card titles |
| **Body Large** | 400 | 18px / 1.75 | 11pt / 17pt | 0 | Intros, standfirsts |
| **Body** | 400 | 16px / 1.75 | 10pt / 16pt | 0 | Default reading size |
| **Small** | 400 | 14px / 1.65 | 9pt / 14pt | 0 | Captions, table cells, footnotes |
| **Eyebrow** | 500 | 12px / 1.4 | 7.5pt / 11pt | 0.2em | Uppercase section labels above headings |

## Rules

- One Display or H1 per page. Never two.
- Heading levels are never skipped — an H3 always sits under an H2.
- The eyebrow label is not a heading. It labels the section that follows and carries no
  heading semantics in markup.
- Body copy is never centred over more than two lines.
- Uppercase is always tracked. Montserrat's caps are wide already; set without
  added tracking they look accidental rather than deliberate.
